# Kubernetes icon attribution

The `kubernetes-*.svg` files in this directory are sourced without modification from the Kubernetes project repositories and renamed to the InfraStack provider-prefix convention:

- Kubernetes logo: https://github.com/kubernetes/kubernetes/tree/master/logo
- Kubernetes architecture icons: https://github.com/kubernetes/community/tree/main/icons

The Kubernetes logo is governed by The Linux Foundation trademark usage guidelines. Kubernetes is a registered trademark of The Linux Foundation. Use of the artwork here does not imply endorsement or sponsorship by The Linux Foundation, CNCF, or the Kubernetes project.

InfraStack uses the official unlabeled resource SVGs where an authoritative equivalent exists. The labeled control-plane component SVGs are used where the official set provides no unlabeled variant. Renaming changes filenames only and does not modify the SVG artwork.

Components without a direct official icon do not substitute custom artwork. Studio renders its normal initials glyph for those entries.
