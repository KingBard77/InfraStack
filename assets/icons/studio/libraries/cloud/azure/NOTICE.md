# Microsoft Azure Architecture Icons

The SVG files in this directory are Microsoft Azure architecture icons retained from InfraStack's Azure VNet architecture package.

Microsoft owns the Azure service names, trademarks, and icon artwork. These files are included only for creating diagrams that describe Azure architectures. Keep the icons unmodified and follow Microsoft's current trademark and architecture-icon guidance when distributing diagrams or derivative catalogues.

Source: https://learn.microsoft.com/azure/architecture/icons/
