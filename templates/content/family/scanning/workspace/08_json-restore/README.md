# JSON Output Section

Use this section for scanner tools that expose the normalized scan payload.

## Owns

- JSON output panel
- Copy JSON action
- Restore-ready payload boundary
- Empty-first payload state before a scan or restore

## Rules

- The JSON must be generated from the same normalized payload that powers findings and evidence tables.
- Show import or restore controls only when restore behavior is implemented in the final tool.
- Keep output readable and copyable without making JSON the primary first screen.
