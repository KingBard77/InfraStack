How To Use

Use this workflow to move from a rough brief to a reviewed workspace artifact. Start with a preset or focused prompt, generate the first pass, then use the visible controls, stage, inventory, and export options to refine the model before sharing it.

1. Start with a preset or brief

Paste a focused __DOMAIN__ brief into the prompt box, or select a preset when you want a stable pattern.

2. Generate the first-pass diagram

Click Generate Diagram. The workspace applies deterministic extraction rules and builds the first-pass model.

3. Review the generated result

Check the score banner, stage, inventory, and prompt notes to confirm the model matches the intended design.

4. Refine the model in the inspector

Correct or adjust controls until the normalized state matches the intended output.

5. Export or restore the workspace

Use PNG for quick image sharing, SVG for vector output, and JSON when the editable workspace should be restored later.
